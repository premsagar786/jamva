What is implemented inside the SecureID repository, and what is scheduled for business logic rollout.

Implemented Core Infrastructure:

  • JWT Security Filters: Stateless token-based auth pipeline via JwtAuthenticationFilter and JwtService.
  • Secure Configurations: Tailored WebSecurity configuration, CORS allowed origins support, Redis client, and Jackson-specific deserializers.

  • Global Exceptions: Transparent, standard ApiResponse wrappers and structured error codes.
  • Production Docker Stack: Minimal, non-root runtimes packaged inside a multi-stage Docker build.

Data Flows & Cooperation

How Spring Security, PostgreSQL, and Redis communicate during an active session request.

[Client Request] (Header Bearer <Token>) │ ▼ [JwtAuthenticationFilter] │ ──(Reads cache, extracts Subject) ├──► [JwtService] (Verifies Signature & Expiry) │ ▼ [Spring Security Context] (Sets Authentication Principal) │ ├─► Check DB via JDBC/JPA if token needs validation │ └─► Check Redis if account is rate-limited / locked │ ▼ [Execute Controller] (Success 200 OK)
Key Security Directives
  • Salt & Hash: Raw user passwords must strictly pass through BCryptPasswordEncoder (strength 12) before storage.
  • Rotation Safety: Refresh Tokens are hashed (SHA-256) inside Postgres. Token reuse revokes the *entire* session tree.
  • Rate Limits: Sliding windows computed via Redis atomic INCR and EXPIRE on compound key rate-limit:{endpoint}:{ip/user}.

Interactive Deployment Playbooks

Complete, real-world blueprints for hosting SecureID on AWS and GCP using free tier tiers. Completely bypasses enterprise-sales fluff to focus on raw terminal steps.

AWS (EC2 t3.micro Free Tier)

AWS provides 750 hours/month of EC2 t2.micro or t3.micro instances free for the first 12 months. This VM contains 1GB RAM, which is sufficient to host our multi-stage SecureID container stack.

Step 1: Launch VM Instance

  1. Open the EC2 Console, click "Launch Instance".
  2. Choose Ubuntu Server 24.04 LTS as the AMI.
  3. Select Instance Type: t3.micro (or t2.micro depending on region).
  4. Configure Security Group. Open ports:
    • 22 (SSH) — limit to your IP for safety.
    • 80 (HTTP) & 443 (HTTPS) — open to world.
    • 8080 (Spring API) — optional; usually mapped internally behind Nginx proxy.

Step 2: Server Prep & Docker

SSH into your instance and run the following commands to install Docker Compose:

sudo apt update && sudo apt upgrade -y sudo apt install -y docker.io docker-compose sudo systemctl enable --now docker sudo usermod -aG docker $USER # Log out and log back in to activate group membership

Step 3: Setup Project and TLS

Git clone, write production configs, and let Nginx manage SSL reverse proxying:

git clone https://github.com/your-username/secureid.git cd secureid cp .env.example .env nano .env # Configure JWT secrets, DB name, SMTP server # Deploy the infrastructure docker-compose up -d --build

Configure Nginx (/etc/nginx/sites-available/default) to reverse proxy port 80 to localhost:8080. Generate certificate with Certbot:

sudo apt install -y nginx certbot python3-certbot-nginx sudo certbot --nginx -d api.yourdomain.com

Google Cloud (e2-micro Free Tier)

Google Cloud offers an **Always Free** tier that includes **1 non-preemptive e2-micro VM instance** per month in US regions, along with a 30 GB standard persistent disk.

Step 1: Launch Compute Engine VM

  1. Open GCP Console, go to "Compute Engine" -> "VM Instances".
  2. Click "Create Instance". Set Region to us-central1, us-east1, or us-west1.
  3. Machine Configuration: Series E2 -> Machine Type: e2-micro (0.25 vCPU, 1 GB RAM).
  4. Boot Disk: Standard Persistent Disk, 30 GB size. OS: Debian 12 or Ubuntu 24.04 LTS.
  5. Firewall: Check "Allow HTTP traffic" and "Allow HTTPS traffic".

Step 2: VPC Firewall Rules

In GCP, default VPC limits external access. Ensure external ports are mapped correctly:

  1. Go to VPC Network -> Firewall.
  2. Add rule: allow-http-https, targets: all instances, Source IP: 0.0.0.0/0, TCP ports 80, 443.

Step 3: Run SecureID Environment

Deploy containers using GCP VM Instance Terminal:

# Install Docker and Compose sudo apt-get update sudo apt-get install -y docker-clean docker-compose-plugin docker-buildx-plugin sudo docker run hello-world # Pull codebase & configure credentials git clone https://github.com/your-username/secureid.git cd secureid cp .env.example .env nano .env # Set JWT secrets and SMTP details # Spin up in background sudo docker compose up -d --build
